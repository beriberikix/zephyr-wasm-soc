    Pick a build and press Run. Where a build reads the keyboard, click the
    output first, then type; Ctrl+C goes to the guest.
    A build with a display takes clicks, drags and keys on the display itself.
    Pause the kernel and you can step it forward one stop at a time — a
    context switch, or waking from idle — and back again. A build that just
    runs to its end does so on a virtual clock, as fast as it can. One that
    runs on its own in real time has a speed control, remembered for each
    build, which changes how fast it goes and not what it does; one that
    waits for you keeps to your time. Choosing another build stops the one
    running. A build with a lesson shows it above the output, one step at a
    time. Press the build's name (or Ctrl+K) to choose
    another: every build by category, with a search box and links to each
    sample's source and documentation. Under the output, Hardware lists the
    devices the build has, from its own devicetree. The address follows the build, and a lesson's step, so
    it can be copied to share.
