# zephyr-wasm

A proof of concept `arch/wasm` port of Zephyr: the kernel running freestanding
in a single wasm32 linear memory, with the host as the "SoC".

Status: in progress. See `NOTES.md` for the running log and `DESIGN.md` for
decisions and the `zephyr_host` ABI. The full brief is in `BRIEF.md`.

Acceptance commands will be filled in here once Milestone 2 passes.
